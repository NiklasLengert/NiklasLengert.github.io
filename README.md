# Niklas Lengert — Personal Website

A personal portfolio website introducing Niklas Lengert, a Media Informatics master's student and software developer based in Berlin. It brings together a short biography, career history, selected projects, and contact links.

## Pages

- **Home** — Introduction, background, and interests.
- **My Career** — Education and work experience, organized into selectable tabs.
- **My Projects** — Selected projects with descriptions and technology tags.
- **Contact Me** — Email and social links.

## Built With

- HTML
- CSS
- Vanilla JavaScript

## Run Locally

No build step or package installation is required. Open `src/html/index.html` in a browser to view the site.

To serve it locally over HTTP, run a static web server from the repository root. For example, with Python:

```bash
python3 -m http.server
